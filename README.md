# פרטיטורה

טעם אישי הופך לפרומפט מדויק ל-Suno, וספרייה של מה שעבד.

1. **מתארים** במילים (כתיבה או הקלטה) או **בוחרים** סגנון, אווירה, קצב, קול וכלים.
2. **מעתיקים** את הפרומפט ופותחים את Suno.
3. **שומרים** בספרייה את הפרומפט, הקישור והשיר עצמו.

פיתוח: `npm install`, `npm run dev`. בדיקות: `npm run build && npm test`.
פרטים: `CLAUDE.md`.
